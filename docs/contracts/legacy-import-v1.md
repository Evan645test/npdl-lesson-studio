# R05 舊備份原始副本契約

舊來源與新版 schemaVersion 2 的設計／評量版本分開保存。新版工作區可選擇帶有 `legacyImports` 陣列；不帶此欄位的既有 v2 備份仍可讀取。每筆副本保存獨立 ID、來源類型、來源版本、原檔名、標題、轉入時間、SHA-256 與完整原始 JSON 字串。新版備份往返與再轉入時保留原始字串，副本 ID 另建；不修改舊題目、規準、來源或施測欄位。

支援兩種來源：原評量工作區 `version: 1`，需有可辨識專案、有效 ID、題組／設計快照及後測的前測參照；原課程專案 `schemaVersion: 1–5`，需有課程表單、設計、評量、課綱選取欄與空的學生證據陣列。這是用於保留來源的結構檢查，不等於完整重跑舊 App 的所有語義驗證。原課程的學生證據非空、疑似憑證欄位、損壞 JSON、未知版本、配對缺失或超過容量時整份拒絕；不抽取部分。自由文字無法可靠自動去識別，教師應在轉入前核對。

舊副本只作唯讀參考，可下載原文；不轉成新版可編輯專案，不自動對應 29 子指標、四階、題型、分數或進程，不寫原工具的儲存鍵。AI 必要資料計畫只取新版選定的課程與題組，不自動帶入 `legacyImports`。教師若要沿用舊課程，須在新版建立並核對新設計。工作區總備份上限 8MB、舊副本最多 20 筆，轉入前先檢查容量；讀檔期間同頁工作區變更時拒絕套用以防覆蓋。
