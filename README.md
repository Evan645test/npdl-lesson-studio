# 深學備課室（NPDL 備課工具）

給高中教師的備課工具：依 108 課綱與 NPDL 深度學習架構，從一個教學主題走到完整逐節教案與可核對的前後測。

**線上使用：** https://evan645test.github.io/npdl-lesson-studio/

## 流程

1. **發想與選擇**：填五項起點（學科、年級、教學主題、單元名稱、核心關鍵字），AI 提出 3 個課程方向，老師選方向、課綱、1–2 個 NPDL 子指標與節數。
2. **學習目標**、3. **證據與規準**、4. **核心活動**：AI 先擬草稿，老師逐項核對、修改、確認；四階規準逐句對應 NPDL 學生版原文。
5. **完整課程**：分批產生逐節教案（任務、學科用途、學生產出、形成性回饋、四階鷹架）。
6. **前後測**：每個子指標選一種方式。
   - **情境進程題**：3 個面向各 1 題選擇（附理由）＋1 題延伸題；前測用生活情境，後測用本課情境。不看對錯，教師依判讀錨點與學生理由判斷四階位置。
   - **課堂學習單＋表現勾選表**：AI 依本課活動產生學習單與教師逐生勾選的四階行為表。
   - **經驗敘述＋參與紀錄**（態度、志趣、價值類子指標預設）：前測請學生寫相關經驗與想法、後測寫課程參與，每題有回想提示、分段小問題與句子開頭；教師另用課堂表現勾選表。前後測證據類型不同，比較條件待確認。
7. **下載成果**：學生卷、教師手冊（判讀錨點、勾選表、班級彙整表）、教案 PDF／Word、判讀提示詞。登入自己的 Google 帳號後，也可以把學生前測、後測直接建成 Google 表單，或把文件存到自己指定的雲端資料夾。

頁面右上角「使用說明」有完整操作說明與常見問題。

## 金鑰與資料

- AI 功能需要教師**自備** OpenAI 或 Google Gemini API 金鑰，在頁面上方「AI 設定」貼上。金鑰預設只在目前分頁；勾選「在這台電腦記住」才會以瀏覽器加密保存在本機。
- 每次送給 AI 前都會列出要傳送的資料並請你同意。送出的只有課程、課綱、子指標原文與老師已確認的內容，**不含金鑰、學生姓名或學生作答**。
- 課程資料存在你的瀏覽器（localStorage），不會上傳到任何伺服器；換電腦或清除瀏覽器資料前，請用「下載工作區備份」保存。
- 這個網站是純前端靜態網頁，沒有後端，也不收集使用者資料。
- Google 表單與雲端資料夾：在瀏覽器以你自己的 Google 帳號授權，只要求「Google 表單」與「本工具使用的雲端硬碟檔案（drive.file）」兩項權限，看不到雲端硬碟裡的其他檔案；登入只在目前分頁有效。建立的表單不收集 Email，學生只填班級代號與座號，不含答案或判讀錨點。

## 資料來源與授權說明

- NPDL 子指標名稱與四階條列依《學生版學習進程》（陳佩英、李哲迪、臺北市 NPDL 校群，2022）抄錄，工具內的四階僅供備課與判讀參考，不代表學生已達到的階段。
- 108 課綱條文為工具內的固定副本，請以教育部公告原文為準。
- 字型 Noto Sans TC 依 SIL Open Font License 1.1 授權（見 `public/licenses/`）。
- AI 產生的內容都需要教師核對；工具不自動判級，也沒有經過學生資料校準。

## 本機執行

需要 Node.js 24。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5193 --strictPort
```

驗證：

```sh
npm run typecheck
npm test
npm run build
```

推送到 `main` 後，GitHub Actions 會自動建置並部署到 GitHub Pages（`.github/workflows/pages.yml`）。

## Google 表單與雲端資料夾設定（網站管理者）

建置時讀取兩個公開設定（不是密碼，見 `.env.example`）：`VITE_GOOGLE_CLIENT_ID`（OAuth「網頁應用程式」用戶端 ID）與選用的 `VITE_GOOGLE_PICKER_API_KEY`（限制 HTTP 參照網址、只允許 Google Picker API）。GitHub Pages 版本由 Actions 的 Repository variables 帶入。自行架設時：在 Google Cloud 啟用 Forms、Drive、Picker API，OAuth 用戶端的「已授權 JavaScript 來源」加入你的網站網址。學校也可在網頁「進階設定」貼上自己的用戶端 ID（只存在該台電腦的瀏覽器）。
